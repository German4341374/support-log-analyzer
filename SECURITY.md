# Security Policy

## Reporting

Report security vulnerabilities privately through GitHub Security Advisories. Do not open a
public issue containing production logs, personal data, API keys, or bearer tokens.

## Data Handling

Analysis is local and the application performs no network requests. Exported recurring-error
examples are masked by default. Masking is a defense-in-depth convenience, not a guarantee that
every organization-specific secret format will be recognized. Review reports before sharing them.
